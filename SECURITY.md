# Segurança do Projeto ARGOS

Este documento orienta o relato responsável de vulnerabilidades. Não abra issue pública contendo segredo, credencial ou dado sensível. Utilize o canal interno definido pela administração do Projeto ARGOS.

Inclua no relato a versão, impacto, passos mínimos de reprodução e evidências sanitizadas. Nunca insira credenciais reais em exemplos. O escopo atual cobre a aplicação Django na branch suportada `master`. A administração fará triagem, priorização, correção, testes e comunicação interna adequada.

O ARGOS ainda não foi homologado para produção. Infraestrutura, implantação e operação segura exigem validação separada.
