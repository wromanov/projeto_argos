# Documentação Estrutural do Projeto ARGOS

Este pacote contém os documentos de referência para continuidade técnica e arquitetural do projeto.

1. `01_visao.md` — visão do produto e problema resolvido.
2. `02_objetivos.md` — objetivos funcionais, técnicos e operacionais.
3. `03_arquitetura.md` — arquitetura atual e direção futura.
4. `04_modelo_de_dominio.md` — entidades, estados e relacionamentos.
5. `05_execution_provider.md` — contrato de execução entre agente e usuário.
6. `06_roadmap.md` — roadmap visual, técnico e funcional.
7. `07_decisoes_arquiteturais.md` — ADRs e decisões oficiais.
8. `08_principios.md` — princípios de engenharia e governança.
9. `09_padroes_de_codigo.md` — padrões de implementação, testes e Git.

Estes documentos devem ser usados em conjunto com o handoff de continuidade do ARGOS.
